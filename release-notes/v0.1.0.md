# TapWheel v0.1.0 — Drag, tap, drop

**Release date:** 2026-10-18

### Install

```text
Download TapWheel-0.1.0-windows-x64.zip from this release, unzip it and run tapwheel.exe
```

---

## Summary

The first release of TapWheel, a file converter for Windows 10 and 11 that works from a drag. Start dragging a file, tap Shift, Ctrl or Alt, and drop it on the wheel that opens under the pointer.

---

## What's included

### Wheels

- Convert (Shift), Tools (Ctrl) and Actions (Alt), with keys you can change or turn off.
- Tap the same key twice to repeat your last choice.
- Slices you pick most move to the top.

### Formats and tools

- Images: JPG, PNG, WebP, AVIF, GIF, TIFF, BMP, ICO, and HEIC input.
- Audio: MP3, M4A, WAV, FLAC, OGG, Opus. Video: MP4, MOV, MKV, WebM, AVI, GIF, and MP3 from video.
- Subtitles: SRT, VTT and plain text. Archives: ZIP, 7Z, TAR, TAR.GZ, packing and extracting.
- Compress, resize, rotate and strip metadata from images; compress, scale, mute and save the sound from video; compress and even out audio.

### Safe by default

- Originals are never changed, and a new file never replaces an existing one.
- Undo sends new files to the Recycle Bin; Cancel keeps nothing.
- No network connections, no account, no telemetry.

### Feels like Windows

- Windows 11 and Windows 10 looks, light and dark mode, your accent colour and high contrast.
- Progress cards with sizes before and after.
- A home window with sample files to practise on.

# TapWheel v0.1.0: Drag, tap, done

**Release date:** 2026-10-18

### Install

```text
Get TapWheel from the Microsoft Store, or download TapWheel-0.1.0-windows-x64.zip from this release, unzip it and run tapwheel.exe
```

---

## Summary

The first release of TapWheel, file tools for Windows 10 and 11 that work from a drag. Start dragging a file, tap Shift, Ctrl or Alt, and drop it on the wheel that opens under the pointer. Pictures, video, sound, icons, text, code and archives, all done on your PC.

---

## What's included

### Wheels

- Convert (Shift), Tools (Ctrl) and Actions (Alt), with keys you can change or turn off.
- The wheel only opens while you're dragging files, and opens and closes with motion you can follow.
- Rest on a slice for its choices on the outer ring. More than eight slices turn into pages.
- Tap the same key twice to repeat your last choice. Slices you pick most move to the top.

### Tools with their own window

- Crop, Add BG, Adjust, Annotate, Redact, Combine and Code shot, with live previews.
- Trim video and sound with a filmstrip and waveform, keep several parts, and make GIFs.
- See every hidden detail in a photo and remove the location before sharing.
- Song tags, archive contents, and password-protected ZIP and 7Z.

### Formats

- Pictures: reads 48 formats including HEIC, JPEG XL, PSD and camera RAW; writes 10.
- Video and audio: 24 video and 33 audio formats in, with MP4, MOV, MKV, WebM, MP3, M4A, FLAC and more out.
- Icons, text, code and archives: ICO and ICNS, Markdown and HTML, format and minify for 30 file types, and ZIP, 7Z and TAR kinds.

### Safe by default

- Originals are never changed, and a new file never replaces an existing one.
- Undo sends new files to the Recycle Bin; Cancel keeps nothing.
- No network connections, no account, no telemetry. Remove BG runs on your PC.

### Feels like Windows

- Windows 11 and Windows 10 looks, light and dark mode, your accent colour and high contrast.
- Compact progress cards with sizes before and after.

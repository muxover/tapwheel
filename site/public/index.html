Three keys, three wheels

Start dragging any file from File Explorer or the desktop, then tap a key. The wheel opens under your pointer with only what fits that file. Drop on a slice and the result shows up on a card.

  1. Shift

    Convert

    Pick a format. The new file lands next to the old one, named so nothing gets replaced.

  2. Ctrl

    Tools

    Crop, trim, compress, resize, remove the background and more, for that kind of file.

  3. Alt

    Actions

    Copy, rename, move, share, see what a file really is, or float it on screen for later.

Seven kinds of file, one wheel

The wheel only shows what makes sense for the file you're holding. When there are more than eight tools, roll the mouse wheel or press Tab for the next page.

Nothing leaves your PC

Online converters need a copy of your file. TapWheel doesn't connect to anything, and it takes care with the files already on your disk.

  • No uploads

    Everything runs on your PC, even Remove BG, with a model that ships inside the app.

  • Originals stay

    New files land next to the old one and never replace a file that's already there.

  • Checked before it starts

    A job that can't read its file or would fill the disk says so instead of starting.

  • Careful Undo

    Undo sends the new file to the Recycle Bin, and only if you haven't changed it since.

  • No account, no tracking

    There's nothing to sign in to, and the app has no telemetry, analytics or update checks.

  • Photo privacy

    See every hidden detail in a photo and take the location out before you share it.

Looks like your Windows

TapWheel follows light and dark, your accent colour and high contrast. On Windows 11 the wheel has rounded corners and frosted glass behind it, and on Windows 10 it turns flat and square to match the rest of the system.

Questions

Is it free?

Yes. TapWheel is free and open source under the GPL-3.0 license. There's no paid version, trial or account.

Why does it watch my keyboard?

To notice a tap of Shift, Ctrl or Alt while you're dragging a file. TapWheel only reacts to those keys, Tab and Esc, never records what you type, and passes every key and click on untouched.

What if I'm not dragging a file?

Then nothing happens. The wheel only opens when what you're dragging is a file or folder, so tapping Shift while you select text is just Shift.

Won't Shift turn my drag into a move?

Not when you drop on the wheel. TapWheel always works on a copy, so the original stays where it was. Dropping anywhere else works the way Windows always does.

Does it need anything else installed?

No. FFmpeg, the Remove BG model and everything else it needs ship inside the app. The tool windows use WebView2, which comes with Windows 10 and 11.

Does it work on Windows 10?

Yes, on Windows 10 version 1809 or later and on Windows 11, on 64-bit Intel and AMD PCs.

Why doesn't the wheel open in some windows?

Windows doesn't let normal apps see drags that start in an app running as administrator. Drags from File Explorer and the desktop always work.

Is this Tangerine for Windows?

No. Tangerine is a separate Mac app by another developer. TapWheel borrows the idea of working from a drag and is built from scratch for Windows.

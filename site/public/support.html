Help with TapWheel

Get in touch

Email contact@muxover.com, or open an issue on GitHub. Include your Windows version, whether you use the Store or zip version, and the kind of file you dragged.

The wheel doesn't open

  • Check that TapWheel is running: its icon sits in the tray, next to the clock.
  • Tap the key quickly while the mouse button is still down. Holding it down for longer than a moment doesn't count as a tap.
  • Make sure Pause isn't on in TapWheel's window.
  • Drags from apps running as administrator can't reach TapWheel. Drags from File Explorer and the desktop always work.

A conversion failed

The card in the corner shows the reason. Some files are damaged or use a format the converter can't read. If the same file opens fine elsewhere, send it to us with the message from the card.

Undo and cancel

Undo moves the new files to the Recycle Bin, so you can still restore them. Cancel stops the conversion and keeps nothing. The original is never changed either way.

Uninstall

Store version: right-click TapWheel in the Start menu and choose Uninstall. Zip version: quit it from the tray icon and delete its folder. The right-click entry it added goes away once you delete the TapWheel keys under HKEY_CURRENT_USER\Software\Classes\*\shell and Directory\shell.
